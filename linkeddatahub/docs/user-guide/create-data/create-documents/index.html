Create documents

Learn how to create container and item documents

Create a container

To create a container document (which can have child documents) with a custom URL, follow these steps:

  1. Click the Create expand_more dropdown in the action bar and select Container. This will open a new form.
  2. Fill out the mandatory Container fields in the form: enter Categories as the Title
  3. To customize the container URL, click on the dropdown in the top-right corner of the form
  4. Replace the generated unique relative URI with categories
  5. Click Save

With the LDH_* environment variables supplying the certificate and base URI, execute the following command:

ldh create container \
  --title "Categories" \
  --slug "categories" \
  --parent "$LDH_BASE"

A container titled Categories should appear with the URI ${LDH_BASE}categories/.

Any text works as the URI path segment — characters outside RFC 3986's unreserved set (letters, digits, -, ., _, ~) are percent-encoded.

Create an item

Items are created the same way:

Select Item from the Create expand_more dropdown instead and follow the same steps as above.

Execute the following command:

ldh create item \
  --container "${LDH_BASE}categories/" \
  --title "Beverages" \
  --slug "1"

The command prints the created document's URL — ${LDH_BASE}categories/1/.
