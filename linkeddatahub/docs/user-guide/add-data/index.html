Add data

Copy RDF data from Linked Data resources and file uploads into your dataspace

Forking copies the contents of any RDF document into a named graph in your dataspace. Two sources of RDF are supported: RDF resources on the web (Linked Data) and RDF file uploads.

info

Adding data this way will cause a blocking request, so use it for small amounts of data only (e.g. a few thousand RDF triples). For larger data, use asynchronous RDF imports.

To copy the contents of the current RDF document (local or remote) into a local document, follow these steps:

  1. Choose Save as in the action bar's Actions dropdown. A form will open with the following fields:
    Source
    URI of the source document
    Graph
    The target document. The source data is appended to the target document's existing content, replacing nothing. You can start typing to find the document by its label, or paste its URI here.
  2. Click Save to perform the fork operation.

For example, the Northwind Beverages category maps to the UNESCO Thesaurus concept Beverages. Open it in the Linked Data browser and fork it into your own dataspace.

The target document does not have to be local: you can also add data to a document in another dataspace by pasting its URI. The append is performed with your identity, so the target dataspace's access control decides whether it is allowed — a refusal surfaces as a form error.

The same fork is a pipe — ldh get the source, ldh post it into the target document:

ldh get --accept text/turtle \
    "https://unesco-thesaurus.demo.linkeddatahub.com/concepts/concept3683/" \
  | ldh post -t text/turtle "${LDH_BASE}categories/1/"

To upload the contents of an RDF file into a document, drag the file from your filesystem into LinkedDataHub when the document's properties mode is active.

The following syntaxes are supported:

Supported RDF syntaxes and their media types
Syntax File extensions Media type
N-Triples .nt application/n-triples
Turtle .ttl text/turtle
RDF/XML .rdf, .owl application/rdf+xml
JSON-LD .jsonld application/ld+json

Browse data to find resources worth forking, or import RDF data for larger datasets.
