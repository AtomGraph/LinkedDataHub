Tutorial

Build your first Knowledge Graph dataspace, from empty to published

This tutorial rebuilds the Northwind Traders demo dataspace: the iconic sample database, reborn as an RDF Knowledge Graph. Every stage ends with a result you can see in the browser. Most steps are shown in two ways: point-and-click in the user interface, and as CLI commands you can script, version and replay. If you are new to the platform, About LinkedDataHub introduces the ideas this tutorial exercises.

Before you start, you need a running LinkedDataHub instance and the owner's WebID certificate. The Get started section covers both.

The command line examples use the ldh CLI. Download it from a LinkedDataHub release (ldh-<version>.tar.gz, needs Java 21), or build it from source with make cli. The examples rely on its environment variable defaults, set once per shell session:

export LDH_BASE="https://localhost:4443/"
export LDH_CERT_FILE="ssl/owner/keystore.p12"
export LDH_CERT_PASSWORD="..."   # the owner_cert_password secret
